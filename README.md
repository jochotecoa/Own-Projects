# Own-Projects

A collection of personal R projects, tutorials, and experiments.

## Project Structure
- **`scripts/`**: Core logic and analysis scripts.
    - **`covid19/`**: Analysis of ECDC COVID-19 data, including case/death tracking and animations.
    - **`machine-learning/`**: Experiments with deep learning (Keras), classification tutorials, and standard ML datasets (e.g., Boston housing).
    - **`utils/`**: Shared utility functions (`functions.R`).
- **`output/`**: Generated results, including plots and animations.

## Highlights
- **COVID-19 Analysis**: Scripts to fetch global data and generate time-series visualizations.
- **Machine Learning**: Practical implementations of Keras for deep learning in R.

## Getting Started
Most scripts expect to be run from the project root. Shared functions are located in `scripts/utils/functions.R`.
